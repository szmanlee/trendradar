## 🛠️ 2026-02-24 09:02-09:37 UTC - 2680 端口反复宕机修复

### 问题
- **症状**: 2680 端口（trendradar 静态文件服务器）多次宕机
- **原因**: `nohup python3 -m http.server` 启动的服务不稳定，异常退出后不会自动重启
- **发生次数**: 2 次宕机（09:02 UTC 和 09:37 UTC）

### 解决方案：创建 systemd service
```bash
# 创建服务文件
cat > /etc/systemd/system/trendradar-2680.service << 'EOF'
[Unit]
Description=TrendRadar HTTP Server (port 2680)
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/.openclaw/workspace/trendradar/output
ExecStart=/usr/bin/python3 -m http.server 2680
Restart=always
RestartSec=5
StandardOutput=append:/tmp/2680.log
StandardError=append:/tmp/2680.error.log

[Install]
WantedBy=multi-user.target
EOF

# 启用并启动
systemctl daemon-reload
systemctl enable trendradar-2680
systemctl start trendradar-2680
```

### 修复后状态
- ✅ 服务状态：`active (running)`
- ✅ 自动重启：已启用 (`Restart=always`)
- ✅ 开机自启：已启用 (`enabled`)
- ✅ 后续监控：10:06 UTC 检查显示稳定运行
